The standalone editor embeds its tested 2.4 Screen follower and archive-converter WebAssembly modules. They run in the browser only; the FM-1 firmware in this release is the validated 2.2-based binary. Complete corresponding sources: apply 2.4-overlay.patch to a copy of this repository (git apply web/embedded-module-sources/2.4-overlay.patch), copy generated/*.h into build/gen/, and build web/emu/cast_follow.c with Emscripten -O2 -ffp-contract=off -std=gnu99 --no-entry -sSTANDALONE_WASM=1 -sSTACK_SIZE=1048576 -sINITIAL_MEMORY=33554432 -sFILESYSTEM=0, including firmware/src and build/gen. The converter sources/build script are web/conv/. GPL-3.0-only; original notices are preserved. Do not apply this browser-module source overlay to the release firmware build.
