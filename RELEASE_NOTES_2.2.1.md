Sillage 2.2.1 for the M-VAVE FM-1 — based on Skiff and Felucca.

This release uses the exact firmware validated by the maintainer on a physical FM-1. It retains the original 2.2 reverb processing and adds only long-press FX latching and a dry-only live filter, independent of reverb/delay returns.

The updated web editor provides larger controls grouped by module, factory/personal sound families with engine search, and temporary A/B sound comparison. FM6 operator patches and Drum-X kit instruments are included in snapshots. Track volume, pan, mutes, groove, sequence notes and global effects are preserved; A/B never writes presets or projects to flash automatically.

- [Web editor](https://lelacnoir-lab.github.io/Sillage/editor.html)
- [USB installer](https://lelacnoir-lab.github.io/Sillage/installer.html)

The ZIP contains the firmware, standalone installer, standalone editor, guides, checksums and corresponding sources. Previous versions remain available under Releases.
