Sillage 2.2.2 — HOME Large display fix

- HOME in DISPLAY → LARGE now shows all eight tracks in two columns of four. Previously the layout still used three rows per column, placing T7 and T8 outside the screen.
- The selected track remains highlighted; sound names and the four large parameter cards are retained.
- Audio processing is unchanged from 2.2.1: original 2.2 reverbs, long-press FX latch and the dry-only live filter remain.
- No project or preset format changes. This release fixes the display; physical FM-1 confirmation of this new layout is still welcome.

The release build checks the layout for every selected track, muted/unmuted tracks and both panel heights, and verifies that other compiled source inputs still match the validated 2.2.1 baseline. Normal firmware memory and loader checks also run.

Based on Skiff and Felucca. The previous 2.2.1 release remains available.
